# RFID 信号监视工具设计

## 目标

建立独立的 Windows 桌面程序，直连 E720 RFID 读写器，用于查看每次原始标签检测的 EPC 与 RSSI 强度，并以时间为横轴实时绘制信号曲线。

该工具是信号观测工具，不包含计时、名单匹配、8 秒去重、RSSI 峰值结算或任何固件模拟逻辑。

## 位置与启动

程序位于 `D:\WorkProject\计时系统文件及备份\RFID信号监视`，与现有计时测试软件相互独立。它使用 Python、Tkinter 和 pyserial，提供独立的 `run.py` 启动入口。

## 用户界面

主窗口左右分栏。

左侧提供串口下拉框、刷新串口、波特率、连接/断开、轮询模式选择、开始/停止和状态提示。串口名称继续将 CP210x 等读写器端口标为“RFID芯片”。下方表格按最近检测时间倒序，显示完整 EPC、最新 RSSI、检测次数和最后检测时间。每一条读写器标签通知均立即更新相应行。

右侧为实时 RSSI 曲线。横轴为检测发生后的相对秒数，纵轴为 dBm。不同 EPC 使用稳定的不同颜色。图表显示最近 60 秒的数据；到期数据从显示缓存移除，表格中仍保留标签的最新值和累计次数。

## 读写器交互

* 被动模式：发送多次盘点启动命令 `BB 00 27 00 03 22 FF FF 4A 7E`，接收连续通知；停止时发送 `BB 00 28 00 00 28 7E`。
* 主动模式：后台发送线程每 100ms 发送一次单次盘点命令 `BB 00 22 00 00 22 7E`；读线程持续解析返回的标签通知。停止、断开与关闭窗口时立即停止该发送线程。

两种模式共用 E720 标签响应解析：显示完整 EPC 和带符号 RSSI，不截取前 4 字节。

## 模块划分

* `protocol.py`：命令构造、E720 帧解析，以及完整 EPC 标签通知。
* `serial_worker.py`：串口读线程、主动轮询定时线程、被动轮询启动/停止、线程安全事件队列和端口标签。
* `signal_store.py`：按 EPC 保存最新状态、累计次数和 60 秒滚动样本；不含去重或峰值逻辑。
* `app.py`：Tkinter 左右分栏界面、表格刷新和 Canvas 曲线渲染。

## 异常处理

串口不存在、无法连接、写入失败或读线程异常时，界面显示明确状态且保持可重新连接。切换或停止轮询不会阻塞图形界面。关闭窗口时无论当前模式如何均先停止轮询、再关闭串口。

## 验证

自动测试覆盖单次/多次/停止命令、完整 EPC 与 RSSI 解析、主动模式 100ms 调度、原始检测无过滤累计、60 秒滚动样本以及端口 RFID 标注。最后执行完整测试套件并进行应用导入检查。
