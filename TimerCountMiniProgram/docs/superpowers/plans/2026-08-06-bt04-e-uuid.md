# BT04-E UUID Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让微信小程序使用 BT04-E 标准固件的 FFE0/FFE2/FFE1 GATT 映射。

**Architecture:** 仅替换集中配置中的三项 UUID。BLE 传输层继续从配置读取服务、写入和通知特征，上层业务协议不改变。

**Tech Stack:** 微信原生小程序、TypeScript、Node.js test runner、BLE GATT

## Global Constraints

- 设备名称仍为 `ESP32-LORA-BRIDGE`。
- Service/Write/Notify 分别为 FFE0/FFE2/FFE1。
- 原二进制业务帧及 20 字节分片不改变。
