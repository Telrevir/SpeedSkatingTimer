# 运动员定义后8秒去重修正设计

日期：2026-08-15

## 问题

通过`0x10`定义运动员时，固件先正确返回圈数0的`0x12`，但运动员的“已有检测时间”标记为未启用。标签仍在RFID读取区时，紧接着的重复上报会绕过8秒判断，将圈数立即增加到1。

## 修正行为

- 运动员定义成功时，圈数仍初始化为0。
- 将`0x10`命令的处理时刻写入该运动员的最近检测时间，并立即启用其8秒去重状态。
- 定义成功后仍按原协议顺序发送`0xF0`成功和圈数0的`0x12`。
- 定义后不足8秒的同EPC检测完全静默，不增加圈数，不更新总时长，不发送协议。
- 从定义时刻起达到或超过8秒后，下一次有效检测才将圈数从0增加到1。

## 实现范围

仅修改`DetectionController`创建运动员记录时的去重初始值，不修改协议格式、时钟偏移、黑名单、普通EPC或停止清理流程。

## 验证

回归测试覆盖以下边界：

1. 定义返回的初始圈数为0。
2. 定义后同一时刻和第7999毫秒的重复检测均静默。
3. 定义后第8000毫秒的检测有效，圈数增加到1。
4. 现有普通EPC、黑名单、停止清空和协议测试仍通过。
